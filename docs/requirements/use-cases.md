# EduTwin 用例与权限契约

## 契约版本

| 字段 | 值 |
| --- | --- |
| 版本 | `2.0.0` |
| 冻结日期 | `2026-07-15` |
| 数据范围 | 合成匹配学生与公开数据来源 |
| 公网属性 | 课程演示，不具备生产安全属性 |

## 角色

| 角色 | 身份范围 | 数据范围 |
| --- | --- | --- |
| `STUDENT` | 已启用学生账号 | 本人选课、本人答题、本人任务、本人学情画像、本人计划与本人诊断 |
| `TEACHER` | 已启用教师账号 | 本人创建或协作授课课程、课程内学生学情画像与课程驾驶舱；课程所有者维护课程信息与名单 |
| `COUNSELOR` | 已启用辅导员账号 | 管理员分配年级或班级内的学生跨课程汇总；不读取原始答案，不修改学习内容 |
| `ADMIN` | 已启用系统管理员账号 | 账号、角色、辅导员范围、数据版本、模型部署、大模型接口配置和审计记录；不管理课程，不访问学生学习内容 |

## LMS 生命周期

- 课程状态转换为 `DRAFT -> PUBLISHED -> ARCHIVED -> DRAFT`，归档课程不得直接发布。
- 章节和课时采用编辑、发布、撤回、归档和同层排序，不执行硬删除。
- 考核状态为 `DRAFT`、`PUBLISHED`、`CLOSED`、`CANCELLED`、`ARCHIVED`。已产生提交的考核锁定题目与答案。
- 补交、重做和结果申诉统一生成尝试申请。批准结果仅增加一次尝试并可设置个人截止时间。
- 全部尝试永久保留，最高分作为当前成绩。无有效提交时平均成绩为空值。

## 助手边界

- 助手工具仅执行角色范围内的原子只读查询，不执行业务写操作。
- 单次生成最多使用最近 20 条消息、6 次工具调用和 20,000 字符工具结果，总超时为 30 秒。
- 模型不可用、超时或工具 Schema 错误产生可重试失败状态，不生成伪造答案。
- 学生和教师工具不越过课程与学生授权，辅导员工具不返回原始答案，管理员工具不返回学生学习内容。

`ADMIN` 独占全局透明度和治理接口。`COUNSELOR` 接口只返回聚合统计，不返回原始答案或写接口。普通业务响应不得包含追溯对象、画像版本标识、模型版本、数据版本、制品哈希或技术降级原因。

所有资源授权均在业务后端按数据库关系校验。前端路由守卫不构成授权边界。

## 主闭环

1. 学生练习视图获取课程下一题和当前模型版本。
2. 答题记录按课程和本人范围分页读取，提供所选答案、正确答案、知识点、尝试次数与来源。
3. 答题提交携带 `Idempotency-Key`，业务事务原子创建答题事件、分析任务和 Outbox 事件。
4. 接口返回 `202 Accepted` 与 `AnalysisJob(QUEUED)`，请求线程不等待模型或大模型。
5. Outbox 发布器将 `analysis.requested.v1` 写入 `analysis-events`。
6. 分析消费者将任务置为 `PROCESSING`，调用 FastAPI 或规则降级路径。
7. 分析事务写入掌握度、下一题概率、校准风险和不可变画像版本。
8. 规则引擎根据画像版本生成新计划版本，并将固定事实交给诊断工具。
9. 活动 OpenAI 兼容模型只基于工具返回的学情画像与 SHAP 证据生成结构化诊断；异常时生成同结构模板诊断。
10. 完成事务更新当前指针、课程风险事实和持久任务事件，随后刷新 Redis 缓存。
11. SSE 推送终态，学生视图刷新学情画像与计划，教师驾驶舱刷新课程统计。

## 幂等语义

- 幂等作用域为账号、HTTP 方法、资源路径和 `Idempotency-Key`。
- 相同键与相同请求摘要返回原 `AnalysisJob`，响应保持 `202`，不得新增答题事件、任务或画像版本。
- 相同键与不同请求摘要返回 `409 Conflict`。
- 并发重放由数据库唯一约束裁决，缓存不参与正确性判断。

## 降级语义

| 故障 | 完成语义 | 有效版本标识 |
| --- | --- | --- |
| FastAPI 不可用或超时 | 规则掌握度、下一题概率和风险仍产生画像版本与计划 | `rule-mastery-v1`、`rule-next-v1`、`rule-risk-v1` |
| 大模型接口不可用、超时或 Schema 无效 | 模板诊断保持相同 Schema，规则计划不变 | `template-diagnosis-v1` |
| Redis 暂时不可用 | Outbox 保留未发布事实，恢复后重试 | 原任务与消息标识不变 |
| Redis 缓存丢失 | 从 MySQL 重建当前学情画像、课程风险和任务缓存 | 数据与模型版本不变 |

降级成功的分析任务状态为 `COMPLETED`，同时记录 `degraded=true`、降级阶段和有效版本。业务事实无法持久化时任务进入 `FAILED`。

## 非功能约束

- 本地与服务器负载均为 50 个浏览型并发用户，最多 5 个同时答题。
- 缓存读取 P95 小于 `1s`，答题事务 P95 小于 `500ms`，事件至 SSE 完成 P95 小于 `5s`。
- MySQL 重启、Redis 重试、消费者重领和容器重启不得产生重复画像版本或当前指针回退。
- 服务器只公开 Caddy 的 TCP 80；SSH 22 仅承担受限部署管理流量。
