# EduTwin 知识模型卡

## 模型用途

知识模型从 ASSISTments 2009-2010 Skill Builder corrected 非折叠数据学习答题序列。BKT 输出知识点掌握度，验证集选出的 DKT 或 AKT 输出给定历史、目标题目与目标知识点的下一题正确概率。

IRT 和 BKT 作为统一评估候选保留。四个模型使用相同学生切分、相同后首事件集合和相同校准方法。

## 候选模型

| 模型 | 实现 | 训练目标 | 服务角色 |
| --- | --- | --- | --- |
| IRT | 二参数逻辑 IRT；学生能力和题目难度、区分度联合优化 | 事件正确性二元交叉熵与正则项 | 基线与回滚候选 |
| BKT | 按知识点前向后向 EM；稀疏知识点向全局参数收缩 | 序列对数似然 | 固定掌握度模型 |
| DKT | 交互嵌入和 LSTM；按目标多知识点平均 logit | 下一事件正确性二元交叉熵 | 下一题概率候选 |
| AKT | 目标题目问题流与已观测交互流；题目难度调制；带非负距离衰减的因果多头检索 | 下一事件正确性二元交叉熵 | 下一题概率候选 |

## 数据隔离

- 学生稳定哈希切分比例为 `70/15/15`，种子为 `42`。
- 训练分区内部按学生稳定拆分拟合集和校准集。
- 问题和知识点词表仅由训练分区构建。
- 候选选择仅使用验证分区。
- 测试分区在冻结后通过一次性领取状态评估一次。

## 指标与选择

所有候选按事件计算 AUC、Log Loss、15 箱 ECE 和 CPU P95 推理延迟。神经模型延迟按单个在线目标请求计时，不使用整窗耗时除以目标数的摊销值。DKT 与 AKT 的选择首先比较验证 AUC。最大 AUC 与候选 AUC 差值不超过 `0.005` 时，依次选择 Log Loss、ECE 和 CPU P95 更小的模型；完全相同时按模型名称稳定排序。

最终数值指标由 `knowledge-freeze.json` 和 `knowledge-test-metrics.json` 记录。模型卡不复制可能漂移的运行结果。

## 校准

每个候选使用训练分区校准学生的事件输出拟合一维 Platt-logit 校准器。校准器种子、拟合事件数、参数、版本和 SHA-256 均写入候选清单。

## 限制

- 模型只覆盖 ASSISTments 所含的技能练习行为，不代表一般课程能力。
- 未出现在训练分区的题目和知识点映射到 `<UNKNOWN>`。
- 第一条学生事件仅作为历史上下文，不进入统一下一事件指标。
- DKT 与 AKT 的离线事件评估使用与在线推理相同的滚动历史，历史长度上限为冻结 `max_sequence_length - 1`。
- BKT 多知识点事件对各关联知识点应用相同答题结果。
- 训练数据中的平台行为偏差可能影响概率校准和不同群体的误差。
- CPU P95 用于同一验收硬件上的候选比较，不代表所有部署硬件的绝对延迟。

## 制品完整性

冻结清单记录数据哈希、特征合同、训练配置、随机种子、依赖版本、模型制品、校准器、训练日志、验证指标和制品 SHA-256。测试指标引用冻结模型版本和冻结清单哈希。部署只加载哈希验证通过的冻结制品。
