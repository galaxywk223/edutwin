# Code of Conduct

## Standards

Project participation requires respectful, constructive, and technically grounded communication. Acceptable behavior includes clear feedback, acknowledgement of uncertainty, protection of private information, and attention to accessibility and inclusive language.

Harassment, discriminatory language, personal attacks, deliberate disclosure of private information, and sustained disruption are unacceptable.

## Enforcement

Conduct concerns must be reported privately through the repository owner's GitHub profile. Reports are reviewed confidentially. Corrective action may include a warning, removal of content, temporary restriction, or permanent exclusion from project spaces.

This policy applies to repository discussions, issues, pull requests, reviews, and project-related public spaces.
